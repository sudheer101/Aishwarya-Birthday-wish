# Birthday Surprise — Aishwarya 🎂✨

First-version design with two behavior fixes:

1. The birthday note and later sections are completely hidden until **Start the surprise** is clicked.
2. **Start the surprise** plays a separate gentle **Happy Birthday** instrumental. It does not start Kailove.
3. **Kailove** and **Kabhi Kabhi Aditi** remain available only from their own Play buttons.

The generated `assets/happy-birthday-piano.wav` is a simple instrumental birthday tune. It can be replaced later with a preferred Happy Birthday audio file using the same filename.


Opening behavior: the soft Happy Birthday piano loops continuously after the opening button is clicked and stops immediately when the next/present button is clicked.
